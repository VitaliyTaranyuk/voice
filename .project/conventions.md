# Соглашения по коду

Документ уточняется после выбора стека. Базовые правила ниже обязательны сразу.

## Общие

- Изменения минимальны и ограничены задачей
- Стиль кода следует уже существующему в репозитории
- Без лишних комментариев и мёртвого кода
- Без секретов в репозитории (`.env`, ключи, credentials)

## TypeScript (когда появится)

- Строгая типизация, без `any`
- Для неизвестных данных — `unknown`
- Интерфейсы/типы описывать сразу или выносить отдельно

## Vue 3 (когда появится)

- `<script setup lang="ts">`
- `ref` / `computed`, типизированные props и emits
- Логику выносить в composables

## Backend Express + Mongoose (когда появится)

- Ошибки через try/catch
- Входные данные валидировать
- Документы в POJO (`lean` / `toObject`)

## Pinia (когда появится)

- Setup stores
- Для async-действий: `isLoading`, `error`

## HTTP

- Единый axios-инстанс с интерцепторами

## Тесты

- Только по явному запросу
- Vitest + `@vue/test-utils` для Vue-части
